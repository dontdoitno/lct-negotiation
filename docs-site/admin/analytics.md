# Аналитика

Адрес `/admin/analytics`. По каждому сценарию видно, как он проходится на самом деле.

| Колонка | Что показывает |
| --- | --- |
| Прохождений | Число завершённых разговоров |
| Средние метрики | Средние финальные значения по шести метрикам |
| Чем закончилось | Сколько раз договорились, сколько раз вышло время, сколько раз собеседник ушёл |
| Срыв на реплике | Средний номер реплики, на которой разговор обрывался |

Тест-прогоны исключены везде. Иначе собственная отладка портила бы статистику, ради которой экран и нужен.

Пока ни одного завершённого разговора нет, вместо таблицы стоит короткое сообщение об этом.

## Как читать

Средний номер срыва отвечает на вопрос, где сценарий ломает людей. Если он равен трём, проблема в начале разговора: скорее всего стартовое сопротивление слишком высокое или матрица слишком резко реагирует на обычные реплики.

Распределение исходов показывает, проходим ли сценарий вообще. Если договорённостей ноль, а время выходит у всех, стоит посмотреть лимит реплик и пороги доверия у слоёв.
