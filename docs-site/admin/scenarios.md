# Список сценариев

Главная страница раздела, адрес `/admin`. Здесь видно всё, что есть в базе, включая черновики.

## Таблица

| Колонка | Что показывает |
| --- | --- |
| Название | Ссылка на конструктор |
| Сфера | Например «Управление командой» или «Продажи» |
| Тема | Тема переговоров, по ней же группируется пользовательский каталог |
| Характер | Агрессивный, тревожный, рациональный или свой |
| Сложность | Простая, обычная, сложная |
| Статус | Бейдж «Черновик» или «Опубликован» |
| Прохождений | Только настоящие, тест-прогоны сюда не идут |
| Изменён | Дата последней правки |

Сортировка по дате изменения и по числу прохождений. Фильтры по статусу и сфере, поиск по названию и теме. Список сфер собирается из того, что реально есть в базе, поэтому вариантов, которые ничего не находят, в фильтре не бывает.

## Действия в строке

**Редактировать** открывает конструктор.

**Тест-прогон** создаёт помеченную сессию и открывает экран звонка. Подробности на странице [Тест-прогон](test-run.md).

**Дублировать** создаёт копию с припиской «(копия)». Копия всегда становится черновиком, даже если оригинал опубликован: опубликованного дубля никто не ждёт.

**Опубликовать** и **Снять с публикации** переключают статус. Это отдельный запрос, публикация не требует открывать и пересохранять всю форму.

**Удалить** спрашивает подтверждение и удаляет запись. Отменить это нельзя.

## Статусы

Черновик виден только в админке. В пользовательском каталоге нет ни его, ни следов.

Опубликованный сценарий сразу появляется в каталоге. Новая тема образует в нём новую группу, новая сфера новый раздел. Это проверяемо за минуту: создайте сценарий, опубликуйте и откройте `/cases`.

Публикация возможна не всегда. Если обязательные поля не заполнены, конструктор блокирует её и показывает, чего не хватает. Список проверок на странице [Конструктор](constructor.md).

## Пустое состояние

Когда сценариев нет совсем, вместо таблицы появляется предложение создать первый с двумя кнопками, руками или генерацией.

## API

Все роуты требуют роль администратора и отвечают 403 без неё.

| Метод и адрес | Что делает |
| --- | --- |
| `GET /api/admin/scenarios` | Список, включая черновики |
| `POST /api/admin/scenarios` | Создать |
| `GET /api/admin/scenarios/:id` | Один сценарий |
| `PUT /api/admin/scenarios/:id` | Сохранить целиком |
| `PATCH /api/admin/scenarios/:id` | Сменить только статус |
| `DELETE /api/admin/scenarios/:id` | Удалить |
| `POST /api/admin/scenarios/:id/duplicate` | Копия черновиком |
| `POST /api/admin/scenarios/generate` | Черновик по шести полям |

Ошибки возвращаются текстом, а не пустым кодом 500. Для одного частого случая есть прямая подсказка: если схема базы и сгенерированный клиент разошлись, ответ прямо говорит перезапустить сервер разработки.
