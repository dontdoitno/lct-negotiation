## Формат ответа

Верни СТРОГО JSON, без markdown, без пояснений вне JSON, по следующей схеме:

```json
{
  "deltas": {
    "adaptation": 0,
    "trust": 0,
    "resistance": 0,
    "interests": 0,
    "solutions": 0,
    "commitment": 0
  },
  "techniques_used": ["string"],
  "techniques_violated": ["string"],
  "rationale": "1-2 предложения, для разбора после уровня"
}
```

Правила:
- каждая дельта — целое число в диапазоне -2..2;
- `techniques_used` / `techniques_violated` — только названия из списка техник в рубрике выше;
- если реплика нейтральна и не подпадает ни под одну технику — все дельты 0, оба списка пустые;
- `rationale` — коротко, по-русски, на «вы», объясняет именно эту оценку.
